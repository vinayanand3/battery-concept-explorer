Privacy

Updated September 12, 2026

This educational viewer runs in your browser. It has no accounts, file uploads, contact forms, advertising, or analytics. Search text, selection, and display settings remain in page memory and are discarded when you reload or close the page. The application does not set cookies or use browser local storage.

The model is generated from simple geometric primitives. The site does not load private CAD, scanned meshes, reference documents, or bill-of-materials data.

Hosting

GitHub Pages serves this website. GitHub logs and stores visitor IP addresses for security purposes. Hosting-related processing is described in the GitHub Privacy Statement. The application developer does not control GitHub's log retention.

External links

Following a link to another website is subject to that website's practices. No external fonts, embedded videos, or third-party analytics are loaded by this viewer.
